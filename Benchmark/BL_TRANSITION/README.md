# Flat Plate Boundary Layer Transition — Implicit LU-SGS Benchmark

## 物理问题

**高超声速平板湍流边界层转捩** (Ma∞ = 6.0)

- 来流 Mach 6.0，冷壁条件 (Tw/Tr ≈ 0.14)
- 受控转捩（初场多模态扰动诱发，含 Mack 第二模态）
- Re_δ* ≈ 1000 (入口) → ~200,000 (出口)
- 展向周期

## 转捩机制

在入口附近 (x ∈ [10, 20] δ*) 叠加多模态速度扰动（振幅 1% u∞）：

| 模态 | 描述 | 作用 |
|------|------|------|
| 2D T-S / Mack 二模态 | sin(α₁x) | 高超声速主要不稳定模态 |
| 斜波对 | sin(α₁x)·cos(β₁z) | 三维不稳定性，二次失稳 |
| 亚谐波 | sin(α₂x)·cos(β₁z) | 非线性转捩路径 |

扰动包络采用流向高斯衰减 + 法向指数衰减，满足壁面零扰动约束。

## 使用方法

```bash
# 1. 生成网格
cd Benchmark/BL_TRANSITION
julia gen_mesh.jl

# 2. 运行模拟 (单GPU)
cd ../..
mpirun -np 1 julia Benchmark/BL_TRANSITION/run_config.jl 2000

# 3. 验证结果
julia benchmark.jl verify BL_TRANSITION
```

## 验证项

1. **数值稳定性**: 无 NaN，密度/压力正性保持
2. **来流 Mach**: ≈ 6.0
3. **无滑移**: 壁面速度 ≈ 0
4. **摩擦系数**: Cf > 0 且物理合理

# 40-Point True 3D WENO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a 40-point unstructured-style WENO-ZQ scheme for the Star-Stencil in a compressible rotating DNS solver, resolving shock-interface numerical instabilities.

**Architecture:** 
1. **Multiple Sub-stencils:** `spectral_warmup.jl` will explicitly divide the 40 points into 3 sub-stencils: $S_0$ (Central 40-point), $S_1$ (Left-biased 20-point), and $S_2$ (Right-biased 20-point), and use TSVD pseudo-inverses to compute linear weights for each. Memory arrays expand from `(Nj, Nk, 40)` to `(Nj, Nk, 3, 40)`.
2. **WENO-ZQ Blending:** In `Reconstruct.jl` Branch B (characteristic decomposition), we project 40 points into characteristic space, compute $v_0, v_1, v_2$, and reuse the 1D characteristic smoothness indicators ($Is_1 \dots Is_4$) to define $\beta_1, \beta_2, \beta_0$. The sub-stencils are then non-linearly blended using $\gamma = [0.90, 0.05, 0.05]$, effectively eliminating negative weights while guaranteeing optimal fallback properties near shocks.

**Tech Stack:** Julia, CUDA.jl, TSVD.

```julia
@inline function weno_zq_blend(v0::FT, v1::FT, v2::FT, Is1::FT, Is2::FT, Is3::FT, Is4::FT, ss::FT) where {FT}
    β1 = Is2
    β2 = Is3
    β0 = max(Is1, max(Is2, max(Is3, Is4)))
    
    τ = abs(Is1 - Is4) * ss
    ϵ = FT(1.0e-10)
    
    γ0, γ1, γ2 = FT(0.90), FT(0.05), FT(0.05)
    
    α0 = γ0 * (one(FT) + τ / (ϵ + β0 * ss))^2
    α1 = γ1 * (one(FT) + τ / (ϵ + β1 * ss))^2
    α2 = γ2 * (one(FT) + τ / (ϵ + β2 * ss))^2
    
    invsum = one(FT) / (α0 + α1 + α2)
    ω0 = α0 * invsum
    ω1 = α1 * invsum
    ω2 = α2 * invsum
    
    v0_star = (v0 - γ1*v1 - γ2*v2) / γ0
    
    w0 = ω0 / γ0
    w1 = ω1 - ω0 * (γ1 / γ0)
    w2 = ω2 - ω0 * (γ2 / γ0)
    
    return w0 * v0_star + w1 * v1 + w2 * v2
end
```
